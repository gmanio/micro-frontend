Better Living 문서는 **도메인**으로 나뉩니다. SDK는 반응형 레이아웃만 제공하며, 회원·계약 UI/API는 Passport / Admin이 소유합니다.

## 도메인 맵

1. **[계약](/docs/contract/overview)** — **핵심 도메인**. 예약 → 모두싸인 서명 → 보증금 → 입주 (한눈에)
2. **[회원](/docs/member/overview)** — `UserStatus`, 가입·로그인·로그아웃
3. **[SDK Guides](/docs/guides/introduction)** — 설치 · 반응형 · [i18n](/docs/guides/i18n)
4. **[API](/docs/api/responsive)** — `BetterLivingSdkProvider` / `Responsive`

계약 ⊥ 회원 계정 상태. 서명·결제에서만 회원 게이트가 붙습니다.

현재 패키지 버전: **0.1.0** ([Changelog](/docs/changelog)).

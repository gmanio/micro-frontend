Better Living 문서는 **세 도메인**으로 나뉩니다. SDK는 반응형 레이아웃만 제공하며, 도메인 UI/API는 Passport / Admin이 소유합니다.

## 도메인 맵

1. **[계약](/docs/contract/overview)** — 핵심. 예약 → 모두싸인 → 보증금 → 입주
2. **[자산](/docs/asset/overview)** — 사이트 · 호실 · 유닛 · 인벤토리 ↔ 계약 배정
3. **[회원](/docs/member/overview)** — `UserStatus`, 가입·로그인·로그아웃
4. **[SDK](/docs/guides/introduction)** — 설치 · 반응형 · [i18n](/docs/guides/i18n)

계약 ⊥ 회원. 계약 ⊃ 자산 스냅샷 + 인벤토리 점유.

현재 패키지 버전: **0.1.0** ([Changelog](/docs/changelog)).

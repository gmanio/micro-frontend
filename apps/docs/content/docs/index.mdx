`@dndproperty/betterliving-sdk`는 Better Living 앱용 **반응형 레이아웃** 헬퍼입니다.
공개 문서의 핵심은 Better Living **Passport** 회원 인증 플로우(가입 / 로그인 / 로그아웃)입니다. 인증 UI·API는 Passport가 소유하며, SDK v0.1에는 포함되지 않습니다.

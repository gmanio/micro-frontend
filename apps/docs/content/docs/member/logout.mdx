Better Living Passport 로그아웃은 서버 세션 종료와 **로컬 세션 정리**를 함께 수행합니다. API 실패 시에도 로컬 정리는 동일하게 진행합니다.

## 단계

| Step | Action |
|------|--------|
| 1 | 사용자 확인 다이얼로그 (`/passport/settings` / 메뉴) |
| 2 | `postLogout()` |
| 3 | auth store에서 사용자 제거 |
| 4 | `bl-atk`, `bl-rtk` 쿠키 삭제 |
| 5 | Redirect: PWA → `/passport/intro`, 그 외 → `/` |

## Sequence

```mermaid
sequenceDiagram
  participant User
  participant Settings
  participant API
  participant Store

  User->>Settings: confirm logout
  Settings->>API: postLogout
  Settings->>Store: clear user
  Settings->>Settings: delete bl-atk bl-rtk
  Settings->>User: intro or home
```

## Passport 구현 체크리스트

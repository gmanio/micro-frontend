## 1. Registry

`.npmrc` (프로젝트 또는 사용자):

```ini
@dndproperty:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=YOUR_GITHUB_TOKEN
```

토큰은 `read:packages`가 필요합니다. **레포에 토큰을 커밋하지 마세요.**

## 2. Install

```bash
pnpm add @dndproperty/betterliving-sdk
```

Peers:

```bash
pnpm add react react-dom tailwindcss
```

## 3. Styles

```css
@import "tailwindcss";
@import "@dndproperty/betterliving-sdk/globals.css";

/* published package */
@source "../node_modules/@dndproperty/betterliving-sdk/dist/**/*.{js,jsx}";
```

모노레포 workspace면 `packages/betterliving-sdk/src`를 `@source`해도 됩니다.

## 4. Mount

```tsx
import {
  BetterLivingSdkProvider,
  Responsive,
} from "@dndproperty/betterliving-sdk/responsive";

export function App() {
  return (
    <BetterLivingSdkProvider layout="auto">
      <Responsive
        mobile={<p>Mobile shell</p>}
        desktop={<p>Desktop shell</p>}
      />
    </BetterLivingSdkProvider>
  );
}
```

자세한 API: [Responsive](/docs/api/responsive).

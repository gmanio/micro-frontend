`@dndproperty/betterliving-sdk` v0.1은 Better Living 앱에서 **mobile / desktop 레이아웃을 한곳에서 해석**하기 위한 얇은 CSR 레이어입니다.

## In scope

- `BetterLivingSdkProvider` — `layout="auto" | "mobile" | "desktop"`
- `useLayout()` — 해석된 `"mobile" | "desktop"`
- `<Responsive mobile={} desktop={} />` — 슬롯 합성
- `./globals.css` + Tailwind `@source`

## Out of scope (v0.1)

- Passport 가입/로그인/로그아웃 UI·API ([Flows](/docs/flows/overview)로만 문서화)
- `screens/*` feature 화면 패키지
- betterliving-ui 컴포넌트 카탈로그 (별도 패키지)

인증은 Better Living Passport가 소유하고, SDK는 레이아웃 계약만 제공합니다.

패키지는 `globals.css`에 Tailwind v4 `@theme` 토큰과 베이스 스타일을 둡니다.

```css
@import "@dndproperty/betterliving-ui/globals.css";
```

## 커스터마이즈

앱에서 CSS 변수(`--primary`, `--radius` 등)를 덮어쓰거나, 프로젝트 `@theme`으로 확장하세요. 컴포넌트는 `className`으로 조합하는 것을 전제로 합니다.

## Dark mode

패키지 globals는 `.dark` 변형을 지원합니다. 루트에 `class="dark"`를 올리면 토큰이 전환됩니다.

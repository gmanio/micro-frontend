# `@dndproperty/betterliving-sdk`

React + Tailwind v4 helpers for Better Living apps.

## Install

```bash
pnpm add @dndproperty/betterliving-sdk
```

Peers: `react`, `react-dom`, `tailwindcss` ^4.3.3.

## Exports (v0.1)

| Export | Purpose |
|--------|---------|
| `./globals.css` | Tailwind entry + `@source` for this package |
| `./responsive` | `BetterLivingSdkProvider`, `useLayout`, `Responsive` |

No `screens/*` in v0.1 — feature UIs stay in Passport / Better Living apps.

See `apps/docs` (Flows for Passport auth; Guides/API for this package).
